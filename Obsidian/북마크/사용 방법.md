# 📖 북마크 사용 방법

> 상위: [[00 북마크 홈]]

## 1. 파일 구성
| 파일 | 내용 | 공유 |
|---|---|---|
| `bookmarks_정리본.html` | 개인정보를 뺀 정리본 (943개, 14개 폴더) | 공유해도 됨 |
| `00 북마크 홈.md` ~ `14 정리 후보.md` | 옵시디언에서 보는 분류별 링크 노트 | 공유해도 됨 |
| `🔒 개인정보(로컬 전용)/개인정보_북마크.html` | 개인 계정·문서·내부망 주소 82개 + 로그인 메모 62개 | **내 PC에만** |
| `🔒 개인정보(로컬 전용)/개인정보 북마크.md` | 위 내용을 옵시디언 노트로 | **내 PC에만** |

## 2. 옵시디언에 넣기
1. 받은 `북마크정리.zip`의 압축을 풉니다.
2. `북마크` 폴더를 통째로 옵시디언 볼트 폴더 안에 복사합니다.
3. 옵시디언에서 `00 북마크 홈`을 열면 목차가 나옵니다. 오른쪽 위 ⋯ → **북마크에 추가**(또는 고정)하면 편합니다.
4. 볼트를 Obsidian Sync·iCloud·Google Drive·GitHub로 동기화한다면 `🔒 개인정보(로컬 전용)` 폴더는 **볼트 밖**(예: `내 문서\개인`)으로 옮기세요.

## 3. 브라우저(Chrome·Edge) 북마크로 쓰기
1. **기존 북마크 백업**: `Ctrl+Shift+O` (북마크 관리자) → 오른쪽 위 ⋮ → **북마크 내보내기**
2. (깔끔하게 바꾸려면) 기존 북마크바의 폴더·링크를 모두 선택(`Ctrl+A`)해서 삭제
3. ⋮ → **북마크 가져오기** → `bookmarks_정리본.html` 선택
4. 같은 방법으로 `개인정보_북마크.html`도 가져오면 `🔒 개인정보 북마크` 폴더가 생깁니다.
5. 가져온 폴더는 `가져온 북마크` 안에 들어가므로, 안의 폴더들을 **북마크바로 끌어 옮기면** 끝납니다.
6. `🗂 정리 후보` 폴더를 훑어보고 필요 없는 링크는 지우세요.

## 4. 보안 권장 사항
- 북마크 제목에 비밀번호를 적지 말고 **Chrome 비밀번호 관리자**(설정 → 자동 완성 → 비밀번호 관리자)나 Bitwarden에 저장하세요. 옮긴 뒤에는 `개인정보 북마크.md`의 메모를 지우세요.
- 원래 북마크 제목에 있던 **GitHub 토큰(`ghp_…`)은 폐기**하세요: GitHub → Settings → Developer settings → Personal access tokens.
- Chrome 동기화를 켜 두었다면 북마크 제목에 적은 비밀번호도 Google 계정으로 동기화됩니다.
